Vercel에서는 이 저장소를 가져오면 `vercel.json` 설정으로 `dist/`의 화면 파일만 배포합니다. 빌드는 외부 패키지 설치 없이 실행되며 Supabase 주소는 `deployment-config.json`에 설정되어 있습니다. 화면 배포 후 실제 사이트 주소를 Supabase의 `DAL_PUBLIC_ORIGIN`에 설정하고 `classroom` Edge Function도 배포해야 로그인과 저장이 동작합니다. 자세한 절차는 [Supabase 운영 안내](SUPABASE_운영안내.md)를 참고하세요.

부모님과 함께 달을 관찰하고 사진 또는 선택한 달 그림으로 기록하는 웹앱입니다.

**28명이 각자 휴대폰으로 기록하고 선생님이 모아 출력하는 학급용 기능이 추가되었습니다.** 실제 인터넷 접속용 주소는 아직 배포하지 않았습니다. 학급용 시작 방법은 [운영 안내](운영안내.md)를 참고하세요.

**Supabase 운영을 지원합니다.** PC를 켜 둘 필요 없이 화면은 정적 호스팅, 로그인·기록·압축 사진은 Supabase Edge Function과 PostgreSQL로 처리합니다. 최초 설정과 배포, 기록 이전·백업 복원은 [Supabase 운영 안내](SUPABASE_운영안내.md)를 따르세요. 실제 프로젝트 연결과 인터넷 배포는 별도로 필요합니다.

Supabase 프로젝트 **하나에서 4개 반**을 운영합니다. `teacher1`~`teacher4`는 각자 자기 반의 명단·기록·보고서·QR·백업·비밀번호만 관리합니다. 기존 단일 학급 데이터는 첫 번째 계정으로 보존됩니다. 이미 첫 번째 SQL을 설치했다면 [4반 전환 안내](SUPABASE_4반_설정.md)부터 진행하세요.

학생은 공통 사이트에서 **반 + 번호 + 학생별 4자리 PIN**으로 접속합니다. 선생님은 관리실의 **접속 정보**에서 PIN을 확인·재발급하고, 접속 안내 카드로 출력할 수 있습니다. PIN 5회 오입력 시 선생님의 재발급 전까지 PIN 로그인이 잠깁니다. 기존 전용 링크도 사용할 수 있습니다. 기존 설치에는 `202609070003_student_pin.sql`을 한 번 적용합니다. 백업에는 PIN이 포함되지 않으며 학급 복원 시 새 PIN을 발급합니다.

- 학급용: Python 서버를 실행하거나 호스팅에 배포합니다. 학생은 전용 링크·QR로 접속하고, `/teacher`에서 담임선생님이 비밀번호로 로그인합니다. 기록과 사진은 서버 데이터베이스에 저장됩니다.
- 기존 개인용: `index.html`을 파일로 직접 열면 브라우저에만 저장하는 이전 방식으로 사용할 수 있습니다.

## 사용하기

1. 학년·반, 번호, 이름, 관찰 장소를 적습니다.
2. 달력의 날짜를 눌러 달 모양을 고르거나 사진을 넣습니다. 휴대폰에서는 ‘사진 찍기’로 카메라를 사용할 수 있습니다. 기기와 브라우저에 따라 파일 선택 창으로 열릴 수도 있습니다.
3. 관찰 시각과 한 줄 관찰을 적고 저장합니다. 저장된 날짜를 다시 누르면 수정하거나 삭제할 수 있습니다.
4. ‘관찰하며 알게 된 점’을 적고 ‘인쇄 / PDF 저장’을 누릅니다. 선택한 달을 A4 세로로 출력합니다. 인쇄 창에서 머리글·바닥글을 끄면 더 깔끔합니다. 매우 긴 ‘알게 된 점’은 다음 장으로 이어질 수 있습니다.

원본 `달관찰.pdf`의 관찰 주제·장소·주의할 점·요일별 표·알게 된 점 구성을 따릅니다. 원본의 고정 4주 표는 한 달 전체를 담는 4~6주 달력으로 확장했습니다. 달 모양은 실제로 관찰한 모습을 사용자가 선택하며, 날짜로 예측한 달 모양을 자동 기입하지 않습니다. 음력 날짜는 브라우저의 내장 음력 달력 기능을 사용합니다.

## 저장 및 휴대폰 사용

아래 localStorage 설명은 개인용에 해당합니다. Supabase 학급용은 서버 DB에 저장하며 학생별 5MB 제한을 적용합니다. 사진도 별도 Storage 버킷 없이 압축된 상태로 DB에 함께 저장합니다.

기록과 사진은 사용한 브라우저의 localStorage에 저장됩니다. 사진은 긴 변 640px 이하의 JPEG로 줄여 저장합니다. 브라우저 데이터 삭제·시크릿 모드 종료·다른 기기 사용 시 기록이 유지되거나 동기화되지 않습니다. ‘기록 내보내기’로 JSON 백업을 보관하고 다른 기기에서 ‘불러오기’ 할 수 있습니다. 불러오기는 현재 기록 전체를 교체합니다.

학급용은 정적 웹 호스팅이나 `python -m http.server`만으로 동작하지 않습니다. [운영 안내](운영안내.md)의 학급 서버를 사용하세요. 파일로 열었던 개인 기록을 학급용으로 옮기려면 개인용에서 JSON을 내보내고, 학생의 전용 링크로 접속한 후 불러오면 됩니다. 학급에서 지정한 이름과 번호는 유지됩니다.

브라우저 화면은 외부 폰트·분석 도구를 사용하지 않습니다. 학급용 서버는 Flask, Waitress, qrcode를 사용합니다. 학급용 기록과 압축된 사진은 운영하는 서버로 전송됩니다. QR 코드는 서버 내부에서 생성하며 외부 QR 서비스에 학생 링크를 보내지 않습니다.
